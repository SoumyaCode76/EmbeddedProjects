================================================================================
                        4. ARM GDB COMMAND CHEATSHEET
================================================================================

╔══════════════════════════════════════════════════════════════════════════════╗
║                        CONNECTION & BASIC CONTROL                           ║
╚══════════════════════════════════════════════════════════════════════════════╝

 ┌─ Connect to OpenOCD ──────────────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) target remote localhost:3333                                       │
 │  (gdb) target extended-remote localhost:3333                              │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

 ┌─ Load & Control ──────────────────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) load                          # Load program                       │
 │  (gdb) load firmware.elf             # Load specific ELF                  │
 │  (gdb) monitor reset halt            # Reset and halt target              │
 │  (gdb) monitor reset run             # Reset and run target               │
 │  (gdb) continue                      # Continue execution                 │
 │  (gdb) monitor halt                  # Halt execution                     │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

╔══════════════════════════════════════════════════════════════════════════════╗
║                         BREAKPOINTS & STEPPING                              ║
╚══════════════════════════════════════════════════════════════════════════════╝

 ┌─ Set Breakpoints ─────────────────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) break main                    # Break at main function             │
 │  (gdb) break *0x08001234             # Break at address                   │
 │  (gdb) break filename.c:42           # Break at line number               │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

 ┌─ Manage Breakpoints ──────────────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) info breakpoints              # List all breakpoints               │
 │  (gdb) delete 1                      # Delete breakpoint 1                │
 │  (gdb) clear main                    # Clear breakpoint at main           │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

 ┌─ Stepping Commands ───────────────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) step                          # Step into functions                │
 │  (gdb) next                          # Step over functions                │
 │  (gdb) stepi                         # Single instruction step            │
 │  (gdb) nexti                         # Next instruction                   │
 │  (gdb) finish                        # Step out of function               │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

╔══════════════════════════════════════════════════════════════════════════════╗
║                          MEMORY & REGISTERS                                 ║
╚══════════════════════════════════════════════════════════════════════════════╝

 ┌─ View Registers ──────────────────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) info registers                # Show all registers                 │
 │  (gdb) info registers all            # Show all registers (detailed)      │
 │  (gdb) print $r0                     # Print R0 register                  │
 │  (gdb) print $pc                     # Print Program Counter              │
 │  (gdb) print $sp                     # Print Stack Pointer                │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

 ┌─ Memory Examination ──────────────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) x/10w 0x20000000              # 10 words at address               │
 │  (gdb) x/10b 0x08000000              # 10 bytes at address               │
 │  (gdb) x/10i $pc                     # 10 instructions at PC              │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

 ┌─ Memory Modification ─────────────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) set *(int*)0x20000000 = 0x12345678   # Write to memory            │
 │  (gdb) set $r0 = 0x1000                     # Set register value         │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

╔══════════════════════════════════════════════════════════════════════════════╗
║                        VARIABLES & WATCHPOINTS                              ║
╚══════════════════════════════════════════════════════════════════════════════╝

 ┌─ Print Variables ─────────────────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) print variable_name           # Print variable value               │
 │  (gdb) print *pointer                # Dereference pointer                │
 │  (gdb) print array[5]                # Print array element                │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

 ┌─ Watchpoints ─────────────────────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) watch variable_name           # Watch variable changes             │
 │  (gdb) watch *(int*)0x20000000       # Watch memory location              │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

 ┌─ Auto Display ────────────────────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) display variable_name         # Auto-print on stop                 │
 │  (gdb) undisplay 1                   # Stop auto-display                  │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

================================================================================
                   5. FLASH & DEBUG USING MONITOR COMMANDS
================================================================================

╔══════════════════════════════════════════════════════════════════════════════╗
║                         COMPLETE FLASH SEQUENCE                             ║
╚══════════════════════════════════════════════════════════════════════════════╝

 ┌─ 7-Step Flash Process ────────────────────────────────────────────────────┐
 │                                                                            │
 │  Step 1: (gdb) target remote localhost:3333    # Connect to target        │
 │  Step 2: (gdb) monitor reset halt              # Halt and prepare         │
 │  Step 3: (gdb) monitor stm32f4x unlock 0       # Unlock flash (if needed) │
 │  Step 4: (gdb) monitor flash erase_sector 0 0 last # Erase flash          │
 │  Step 5: (gdb) monitor flash write_image erase firmware.bin 0x08000000    │
 │  Step 6: (gdb) monitor verify_image firmware.bin 0x08000000               │
 │  Step 7: (gdb) monitor reset run               # Reset and run            │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

╔══════════════════════════════════════════════════════════════════════════════╗
║                       STEP-BY-STEP FLASH COMMANDS                           ║
╚══════════════════════════════════════════════════════════════════════════════╝

 ┌─ Method 1: Automatic (recommended) ───────────────────────────────────────┐
 │                                                                            │
 │  (gdb) monitor program firmware.elf verify reset                          │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

 ┌─ Method 2: Manual control ────────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) monitor halt                                                        │
 │  (gdb) monitor flash erase_address 0x08000000 0x10000  # Erase 64KB       │
 │  (gdb) monitor flash write_image firmware.bin 0x08000000                  │
 │  (gdb) monitor verify_image firmware.bin 0x08000000                       │
 │  (gdb) monitor reset run                                                   │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

 ┌─ Method 3: Sector-specific ───────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) monitor halt                                                        │
 │  (gdb) monitor flash info 0                 # Show flash layout           │
 │  (gdb) monitor flash erase_sector 0 0 4     # Erase sectors 0-4           │
 │  (gdb) monitor flash write_image erase firmware.elf                       │
 │  (gdb) monitor reset run                                                   │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

╔══════════════════════════════════════════════════════════════════════════════╗
║                         DEBUG SESSION COMMANDS                              ║
╚══════════════════════════════════════════════════════════════════════════════╝

 ┌─ Start Debug Session ─────────────────────────────────────────────────────┐
 │                                                                            │
 │  arm-none-eabi-gdb firmware.elf                                           │
 │  (gdb) target remote :3333                                                 │
 │  (gdb) load                                                                │
 │  (gdb) monitor reset halt                                                  │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

 ┌─ Set Breakpoints for Blinky Code ─────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) break main                                                          │
 │  (gdb) break main.c:37        # LED toggle line                           │
 │  (gdb) break gpio_pin_toggle_dt                                            │
 │  (gdb) continue                                                            │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

 ┌─ Examine State When Halted ───────────────────────────────────────────────┐
 │                                                                            │
 │  (gdb) print led_state                                                     │
 │  (gdb) print ret                                                           │
 │  (gdb) print led                                                           │
 │  (gdb) info registers                                                      │
 │  (gdb) x/10w $sp              # Stack                                     │
 │  (gdb) x/10w 0x20000000       # RAM start                                 │
 │  (gdb) x/10i $pc              # Current instructions                      │
 │                                                                            │
 └────────────────────────────────────────────────────────────────────────────┘

                               12. PRO TIPS

╔══════════════════════════════════════════════════════════════════════════════╗
║                            EXPERT ADVICE                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

 ┌─ Best Practices ──────────────────────────────────────────────────────────┐
 │                                                                            │
 │  1. Always halt before flashing: monitor reset halt                       │
 │  2. Use load after monitor program: Ensures symbols are loaded            │
 │  3. Set breakpoints before continue: More reliable than during execution   │
 │  4. Use info registers frequently: Monitor CPU state                       │
 │  5. Check memory alignment: ARM requires aligned access for words          │
 │  6. Use monitor prefix in GDB: For OpenOCD commands                        │
 │  7. Start OpenOCD first: Then connect GDB                                  │
 │  8. Use .gdbinit: Automate common setup commands                           │
 │                                                                            │
